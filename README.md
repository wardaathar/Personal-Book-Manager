# 📚 Personal Library Manager

This is a simple **Streamlit app** to help you manage your personal book collection. You can view your saved books, add new ones, and store them in a JSON file locally.

## 🚀 Features

- 📖 View all your saved books with title, author, and year.
- ➕ Add new books through a user-friendly form.
- 💾 Data saved to a local `data.json` file.
- ⚠️ Handles file errors and invalid JSON gracefully.

## 🛠️ Tech Stack

- [Streamlit]([https://streamlit.io/](https://personal-book-manager.streamlit.app/))
- JSON for data storage
